# Ideas

## What is this?

**Ideas** is where you capture what something should become: each idea on its
own, with a **headline**, a **description**, a **project** and a **status**. You
do not need an agent for that. The agent can read your ideas and write next to
them. It does not change your text.

## Capture an idea

1. Write the headline into **"What should it become?"** at the top.
2. If you like, describe what you have in mind in **"What do I have in mind?"**.
   Markdown works, leaving it empty too.
3. Pick a **project** or keep "No project". The last choice is remembered.
4. Press **Capture idea** or **Ctrl+Enter**.

The new idea then appears in the list and is opened on the right.

## The list

- **Project:** all projects, no project, or a single project. With "All
  projects" the list is grouped by project.
- **Status:** the buttons show how many ideas there are per status. At first you
  see the **open** ones (New, Under review, Planned).
- The idea changed most recently is at the top.

## Edit an idea

- Headline and description **save on their own** shortly after you type
  ("saving…" / "saved"). An empty headline is not saved.
- **Preview** shows the description fully formatted.
- Change **status** and **project** with the two select fields.
- **Delete** asks first and removes the idea together with its notes.

## Status

- **New** — just captured.
- **Under review** — someone is looking at it.
- **Planned** — is going to be built.
- **Parked** — not now, but not dropped.
- **Done** — finished.
- **Dropped** — will not be done.

There is no fixed order. You can set any status at any time.

## What the agent may do

- It **reads** your ideas when you refer to them in chat, for example: "Have a
  look at my idea about the admin page."
- It writes **notes** next to your idea. They appear below the description and
  can be deleted one by one.
- It may change the **status**. When it does, the change is recorded as a note.
- It can create **ideas of its own**. The list then says "by the agent".
- It cannot change the headline or description of **your** ideas.

## Ideas and projects

The project is an assignment, not a share: only you see your ideas, even when
they belong to a shared project.

## The earlier free text

Up to version 1 there was one free text for you and one for the agent here. On
first open both are turned into single ideas, split at first-level headings
(`# `). The old files stay on the server.

## When Ideas, when Notebook?

- **Ideas** — what should be built or done some day, with status and project.
- **Notebook** — permanent, titled notes for you.
