# Help assistant

## What is it?

At the bottom right of every page there is a round button with a question mark. It opens the **help assistant**:
a small chat window that knows the HydraHive manual. Ask in plain language; it searches the manual and explains step
by step what to do.

## What can I do here?

- **Ask questions**, for example "How do I create an agent?" or "How do I set up an AI?"
- **Ask about the current page**: "What can I do here?" – the assistant knows which page you are on.
- **Switch pages without losing the conversation**: the window stays open when you change pages, and the history is kept.

## Reporting an error

If something does not work, tell the help assistant, e.g. "I get an error when sending". If the manual does not help,
it offers to report the error to the HydraHive team.

1. If you agree, it creates an **error report**. HydraHive collects the error data itself (your account's error log
   of the last 24 hours, page, versions, system) – you do not have to look for anything.
2. The report appears as a card in the window. Read it.
3. Click **Send**. The report goes to `issue@hydrahive.org` – via the mail account set up under
   **System → Settings → Mail**. Only your click sends it; the assistant itself cannot send anything.

If no mail account is set up, the card shows **Open in mail program**: your mail program opens with the finished
report, you only need to send it. Admins also see the link **Set up mail access**.

The report contains neither your user name nor passwords or keys. An admin can turn error reports off under
**System → Settings → Help**.

## Good to know

- The assistant **only reads** the manual. It cannot change anything: no settings, no files, no terminal.
- It uses the **default model** from the AI settings. If none is set up, the window shows a hint with a
  **"Set up AI"** button.
- If something is not in the manual, it says so and points you to our Discord.
- Every user has their own help assistant with their own history. It does not appear in the agent list.
