# Help assistant

## What is it?

At the bottom right of every page there is a round button with a question mark. It opens the **help assistant**:
a small chat window that knows the HydraHive manual. Ask in plain language; it searches the manual and explains step
by step what to do.

## What can I do here?

- **Ask questions**, for example "How do I create an agent?" or "How do I set up an AI?"
- **Ask about the current page**: "What can I do here?" – the assistant knows which page you are on.
- **Switch pages without losing the conversation**: the window stays open when you change pages, and the history is kept.

## Good to know

- The assistant **only reads** the manual. It cannot change anything: no settings, no files, no terminal.
- It uses the **default model** from the AI settings. If none is set up, the window shows a hint with a
  **"Set up AI"** button.
- If something is not in the manual, it says so and points you to our Discord.
- Every user has their own help assistant with their own history. It does not appear in the agent list.
