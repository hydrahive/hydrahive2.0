# Internationalization of HydraHive documentation

> 🇩🇪 [Deutsche Version](I18N.de.md)

HydraHive product documentation is published in two languages:

| Code | Language | Audience |
|------|----------|----------|
| `*.md` (default) | English | International contributors, reviewers, future hires |
| `*.de.md` | German | Primary user/admin language, customer-facing hand-off |

## Rules

1. **English stays the canonical source.** Every `*.md` file in this repository is the authoritative version. The `.de.md` file is a translated mirror.
2. **One mirror per file.** A translated copy lives next to the English original and shares the same path, only with the `.de` infix before the `.md` suffix.
   - `README.md` → `README.de.md`
   - `docs/ARCHITECTURE.md` → `docs/ARCHITECTURE.de.md`
3. **Visible language pointer at the top.** Every document opens with a single line that links to the other language. Use the real filename in the link, for example `> 🇩🇪 Deutsche Version → README.de.md` or `> 🇬🇧 English version → README.md`; do not use a literal placeholder.
4. **Same structure, same anchors.** The German mirror must keep section headings, link targets and code-block languages identical to the English original. Renaming a heading in English requires the same rename in German and vice versa.
5. **No mixed language in a single file.** Either translate fully or leave the mirror out (and link only to the English version).
6. **Code blocks, paths, identifiers and configuration keys are never translated.** Tables of environment variables, module IDs, API paths, CLI flags and similar stay in English.
7. **Updates travel together.** When the English original is edited, the German mirror must be updated in the same commit (or a follow-up commit that references the original change). Out-of-sync mirrors are reviewed in the same PR.

Files that are already written natively in German (`docs/USER_GUIDE.md`, `installer/README.md`, `SECURITY.md`, `docs/SECURITY_THREAT_MODEL.md`, `docs/RELEASE_NOTES.md`) do not get an English mirror; the German original is canonical for them.
